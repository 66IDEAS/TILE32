TILE32

Your windows side by side, arranged with the mouse.

Getting started

  • TILE32 lives in the menu bar. It needs the Accessibility permission to move windows. If it is missing, choose "Open Accessibility settings..." in the menu and switch TILE32 on.
  • TILE32 starts paused. Choose "Resume tiling" to start, or "Tile now" to arrange the current windows once.
  • Every display and every Space has its own layout, and TILE32 remembers each one.

Moving windows

Drag a window by its title bar and drop it on another window. While you drag, a highlight shows what will happen.

Top: split
Left: split
Centre: swap
Right: split
Bottom: split
  • Drop on the centre of a window to swap the two windows.
  • Drop near an edge to split that window and place yours on that side.
  • Drop close to the left or right edge of a display to give the window the full height there, beside all the others.
  • Drop on another display to move the window there.
  • Press Esc while dragging, and the window goes back to its tile.

Changing sizes

  • Drag the edge between two windows. The neighbour follows, and sizes snap to quarters, thirds and halves.
  • "Make sizes equal" in the menu gives the windows you can see the same share again.

New, closed and extra windows

  • New windows join the layout, and closed windows leave a gap that the others fill.
  • When columns would get too narrow, TILE32 uses a second row.
  • "Window limit" sets how many windows share a display. Extra windows are minimised and come back when you use them.
  • Dialogs, panels, full-screen windows and windows that cannot be resized stay floating.
  • A window that cannot get as small as its tile is marked "does not fit", and the number shows next to the menu bar icon.

Taking a break

  • "Pause tiling" stops all arranging. Windows stay where they are.
  • "Untile" puts every window back where it was before TILE32 moved it, then pauses.
  • "Don't tile" with an app's name leaves that app alone. "Excluded apps" lists them.
